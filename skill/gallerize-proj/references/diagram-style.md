# Gallery 图示参考：SUPER 视觉语言 + 独立输入输出

适用：算法核心图与 Tool / Behavior / Function 图。2026-11-12 用户确认以 SUPER 的克制、低饱和样式为视觉基准，吸收 IPC 将多个输入输出单独展开的表达。统一的是视觉语言，不是算法拓扑。

## 必须实际读取和查看

1. 读取本目录 `diagram-tokens.json`，作为色值、字体、字号、圆角与线条的唯一基准。
2. 读取并渲染 `../templates/algorithm.svg` 与 `../templates/layers.svg`，实际打开渲染图。它们是无算法事实的可编辑模板，不是要求照搬的流程。
3. 开始本次条目绘图前，查看仓库中的 SUPER `gallery/content/algorithms/super/assets/algorithm-unified.svg` 与 IPC `gallery/content/algorithms/ipc/assets/algorithm-unified.svg` 的当前渲染：前者提供探索/备份分支布局，后者提供多个输入输出端口。两者是事实案例，不是模板的依赖；Skill 的 token 与模板可独立使用。

渲染用 Gallery 已有 sharp 或浏览器。检查图写入根目录 log/gallery-review，不依赖这些临时产物才能理解模板。图示仍用原生 SVG，不用整张位图替代。

## 样式和允许变化

- 暖白底、灰黑正文、柔和绿内部节点、红色整体输入输出；框架图蓝灰表示公共复用、浅灰表示外部或未涉及。使用 token，不自行另起鲜绿、冷蓝底和橙色箭头的视觉体系。
- 标题 22px/600，节点标题 23px/600，正文 18px，注释 17px；按实际渲染核对文字宽度，超长先拆行或加宽节点，不为了塞文字无限缩字。
- 节点圆角 8、画布圆角 12、连线宽 2。三层图实线表示执行调用/参考下发，虚线表示数据，包括目标会话、算法结果、状态与地图；算法图主依赖实线、跨时刻反馈虚线。跨图不能交换线型含义。
- 左侧独立输入端口、右侧独立输出端口，均用红色并带输入/输出文字。分别命名真实数据及消费方；不因视觉对称虚构输出，不把内部候选改为整体输出。只有一个输出就只画一个。
- 多个输出如共享同一帧、同一时间戳或共同启停，图注说明耦合关系；分开画端口不等于可独立部署。
- 方法节点数量、分支、反馈、排列、画布比例和走线可按算法改变。优先紧凑的横向阅读，不强制所有图同宽高，也不把复杂图压成不可读缩略图。
- 能力与调用事实先决定节点，再套样式；箭头接边界，留出层间/侧边通道，不穿过标题、正文和无关节点。交叉不表示连接，实际连接处分支标点或采用明确分叉。

`../scripts/diagram_style.py` 提供 token 驱动的原生 SVG 元素，可复用 node/text/edge/frame/svg；布局由条目自己决定。手工编辑 SVG 也必须符合相同 token。运行 `python3 skill/gallerize-proj/scripts/check_diagram_style.py <本次SVG...>` 检查色板、字体和元数据漂移；它不验证布局或架构事实，不能替代实际查看。

## 绘图前的职责证据表

至少列：职责 → 输入/输出 → 源码符号 → 消费者/调用方 → 所在层 → 共享进程 → 实现/验收边界。

分别回答“有无该层职责”和“是否发布通用接口”。通用 Tool 尚未实现，不等于 Tool 侧没有目标转换、执行调用、到达判定、取消交接等实现基础；Demo 中已有这些职责时标 Demo 侧，不冒充独立 Tool 服务。仿真真值评分、碰撞审计和验证门与可复用任务协调分开表述。

联合算法可在一个进程内同时承担路径搜索、地图、MPC 等工作；按项目已确认归属描述内核，并继续向外追踪任务调用和交接，不能仅根据最终输出角速度/推力就宣布整个组件“仅 Function”。此表不改变运行部署，也不自动授权重构算法。

## 跨图验收门

本次图与至少 SUPER、IPC 基准在相同显示宽度并排查看。逐项核对：底色/色板、字体及字重层级、节点圆角与边框、箭头与线型、留白和文字密度、输入输出命名。单图无裁切不等于跨图一致。

修改后重渲染、实际查看桌面和窄屏；窄屏检查可聚焦滚动，框架图核对层级与事实。比较截图、检查报告放 log/gallery-review。没有执行比较时交付明确写未完成视觉一致性验收。样式同步不升级算法验收等级。
