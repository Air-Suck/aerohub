# Component 契约

实现 Harness 前记录每条输入、输出和执行请求；未知项写验证方法，不用默认值冒充事实。

## 数据

| 方面 | 必须确定 |
| --- | --- |
| 来源与消费 | 实际发布者、消费者、版本，测量/估计/真值属性 |
| 字段 | 实际读取与填写字段、单位、范围、缺失和无效语义 |
| 空间 | ENU/NED、FLU/FRD、固定/移动 frame、TF 权威、外参方向 |
| 时间 | 采样、观测、接收、计算、计划起点与执行时刻，时钟域和新鲜度 |
| 版本 | task、revision、地图 epoch、目标世代、模型和配置版本 |
| 失效 | 陈旧、未来、乱序、断流、reset、重启和恢复规则 |

环境表示注明分辨率、覆盖、更新、膨胀与查询语义；单帧传感器、配准点云、占据图、ESDF 和隐式地图分别命名。多机数据注明车辆 ID/顺序、共同时间基准和部分失败策略。

## Function

定义启动前置、ready、health、请求/持续输出、超时、并发、reset、停止和重启。区分进程存活、算法初始化、输入有效、结果新鲜和任务可用。

## Behavior

定义 Goal 接受条件、Feedback、Result、取消、暂停/更新、控制模式、watchdog、资源占用、输出静默和失败交接。计划执行注明采样、P/V/A/yaw 有效字段、严格递增时间、generated/valid 时间、revision 和迟到拒绝。

算法结束、任务到达、低速保持、执行停止、降落和解除武装是不同状态，分别定义判据。

## 发布权与部署

列出状态、TF、地图、时钟、运动参考和控制模式的唯一权威发布者。记录共享进程、GPU/CPU、端口、命名空间、DDS domain、配置、持久状态和冲突资源。
