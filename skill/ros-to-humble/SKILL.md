# ROS to Humble

## 迁移边界与基线

先定位真正的算法源码：已有 ROS 2 adapter 不代表底层算法已迁移，Docker 基础镜像可能才是源码来源。记录仓库、提交、镜像和本地修改；保留上游署名及许可证。若清单与 README 的许可证冲突，记录差异，勿自行把上游重新授权。

追踪当前调用方使用的 service、topic、消息、参数和 launch，明确本轮必须迁移的能力。算法核心、ROS 封装、可视化和仿真分别梳理依赖。只为可视化引入的 ROS 1 工具库，可以通过迁移所需算法入口消除；将未迁移能力写明，并对仍保留的请求字段给出明确响应。

完成条件：源码版本可追溯，输入输出及时间、坐标系、车辆顺序、目标归属语义已列明；真实 ROS 1 基线可运行，或缺失条件已明确记录。

## Humble 实现

- 用 `ament_cmake` / `ament_python` 替代 catkin，更新 `package.xml`。自定义接口使用 `rosidl_generate_interfaces`、运行时依赖和 `rosidl_interface_packages` 组；同包 C++ 节点链接生成的 typesupport target。
- 同包既生成消息又构建库时，让 C++ 库 target 与接口生成 target 使用不同名字；原 ROS 1 库可能与包同名，直接照搬会发生 target 冲突。
- 先检查算法实际用到的类型，再移除间接 ROS 1 头文件依赖。保留算法计算，独立实现 `rclcpp` / `rclpy` 封装。节点名、私有名称解析和服务路径需要运行时检查。
- Humble 的 `ament_target_dependencies` 与 `target_link_libraries` 签名须一致；若出现 keyword/plain 混用错误，统一同一 target 的调用签名。
- 将参数顺序错误等已有缺陷与版本迁移分开记录和验证。用不相等的参数值检验顺序；不要仅凭编译成功判断语义正确。
- 有共享可变状态的算法先使用串行回调；若代理线程等待异步 ROS 2 调用，让独立 executor 推进回调，并给等待设超时。
- 检查所有时间字段的时钟来源，包括默认零值。`rclcpp::Time` 默认值可能是 system clock，而节点 `now()` 是 ROS clock；相减会抛异常。保留原零时间含义时显式指定 `RCL_ROS_TIME`，将消息时间与浮点秒转换为同一时钟类型。
- 将 ROS 1 私有 topic 映射为 ROS 2 的 `~/...`，统一参数键从 `/` 到 `.` 的映射并核对实际值。对照发布者与当前模式订阅的真实路径，不能只照抄 launch 文件名或注释。
- 将 latched 目标发布转为 `TRANSIENT_LOCAL`，同时检查订阅端 QoS 和启动发现时序。图像同步订阅要与实际传感器 QoS 兼容。用真实消息确认目标送达，而不只检查节点存在。
- 更新真实部署 Dockerfile、启动脚本和注册表。旧 ROS 1 包留作对照时加 `COLCON_IGNORE`，避免同名包参与 colcon 发现。
- 本仓库的 ROS 1 对照快照、旧代理和部署归档在 `src/planner/<name>/upstream/`；活动 Humble 实现在 `src/planner/<name>/ros2_adapter/native/`。移动归档时一并更新基线脚本、Docker COPY 和文档引用，保留原版本与许可证。

完成条件：在真实 Humble 环境构建成功，生成的接口可被调用，运行路径不再依赖 roscore、roslaunch 或 ROS 1 代理。

## 行为验证与经验收录

使用相同输入调用真实 ROS 1 / ROS 2 实现，对比数量、顺序、采样时刻及数值结果；允许误差应有依据。另查速度、加速度等物理约束，覆盖静止、重分配、无效请求和失败后的恢复。故意修复的行为单独给出对照。

验证调用方仍能消费结果；有 JSON/TCP 兼容入口时验证它连接的是真实 ROS 2 服务。mock 只证明协议接线。构建、服务数值、adapter 闭环、仿真飞行分别报告验证范围。

滚动规划器还要验证多次输出、目标完成和无效请求后的恢复；首条轨迹通过并不能覆盖完成分支的时间运算。数值对照可冻结算法时钟以固定其他车辆轨迹的相对时间；计算耗时另用单调时钟测量，两版顺序运行，保留预热和重复次数、构建环境及中位数/P95。固定场景的通过不能外推为复杂障碍环境或飞行性能结论。

把可复现命令和具体项目证据放在项目文档；只将确实改变迁移决策的经验收入此技能。第二个项目使用本流程验证，遇到新问题后再修订，明确区分已验证规则与待验证分支。

当前证据见 [迁移记录](references/migrations.md)。
