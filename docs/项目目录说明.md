# 远端项目目录

主工作目录：`RKOH_Remote:/home/noah/code/UAV/aerostack2-integration`。

```text
aerostack2-integration/
├── src/                         # 本项目集成代码及 Planner 源码
│   ├── follow_path_execution/   # 兼容扩展 AS2 FollowPath Behavior
│   ├── planner_framework/       # 配置、轨迹校验、机群 Action 调用与生命周期
│   ├── planner_interfaces/      # ROS 2 消息、服务和 FollowTimedPath Action
│   ├── cat_ora_adapter/         # CAT-ORA ROS 2 适配
│   ├── swarm_formation_adapter/ # Swarm ROS 2 适配
│   ├── adapters/                # ROS 1 侧算法代理
│   ├── as2_setpoint_adapter/    # 显式启用的历史执行链路
│   └── planners/
│       ├── cat_ora/             # CAT-ORA 上游源码子模块
│       └── swarm_formation/     # Swarm-Formation 上游源码子模块
├── as2/
│   ├── aerostack2/              # 官方 AS2 核心子模块
│   ├── as2_platform_pixhawk/    # 官方 PX4 平台适配子模块
│   └── px4_msgs/                # PX4 ROS 2 消息子模块
├── px4/                         # PX4-Autopilot 子模块
├── simulator/
│   └── gazebo/                 # AS2 官方 project_gazebo 子模块
├── deployment/                 # 构建、平台补丁、Compose 与启动入口
├── vendor/                     # 锁定版本的通信依赖源码压缩包
├── tools/                      # 场景及演示工具
├── docs/                       # 架构、设计、使用与历史说明
├── log/                        # 全部忽略：测试日志、配置、缓存、构建及迁移备份
├── .gitmodules                 # 子模块路径与公开上游地址
├── AGENTS.md                   # 架构及开发约束
└── README.md                   # 使用入口
```

`src/planners` 中的算法仍归各自上游所有，目录位于集成代码区不代表原创。
`simulator/gazebo` 是 AS2 官方仿真工程，不是 Gazebo 引擎的 fork。
当前 PX4/Gazebo 多机测试使用 PX4 自带的 Gazebo 集成及镜像提供的 Gazebo Harmonic，
不要求启动 `project_gazebo`，也不把两个仿真入口混为一套。

新克隆使用 `git clone --recurse-submodules`，已有克隆使用
`bash deployment/prepare_sources.sh`。子模块版本由外层 Git gitlink 锁定。
不提交 `log/`；项目根目录不再存放运行日志。基础镜像仍需按部署说明准备。

修改任务使用 `src/planner_framework/examples/`，修改算法默认参数使用
`src/planner_framework/registry/`，运动执行扩展位于 `src/follow_path_execution/`。
详细统一接口和运行方式见 `Aerostack2统一Planner第一阶段接口与配置设计.md`。
