# 项目目录说明

以下为当前 AeroHub 的主要源码和使用入口。本机 SDK、缓存、日志及临时副本不属于交付目录。

```text
AeroHub/

├── config/
│   ├── airsim/                       # nh/town05/plant profile 与车辆 settings
│   ├── as2/                          # AS2、机群与 PID 参数
│   ├── dds/                          # DDS UDP 通信配置
│   └── resources.example.yaml        # 外部场景 binary 位置模板
├── scripts/
│   ├── prepare_sources.sh            # 初始化活动 submodule，保留本地源码修改
│   ├── prepare_ohos_workspace.py     # 从官方环境创建项目隔离工作区
│   ├── prepare_ohos_sources.py       # 日常同步活动 fork 与 PX4 消息覆盖定义

│   ├── airsim.sh / airsim/           # 场景进程管理与资源路径解析
│   ├── load_env.sh                   # 读取可信的本机 .env
│   └── diagnostics/                 # 离线探针及板端内存检查
├── deployment/
│   ├── README.md                     # 交付清单、依赖准备与使用顺序
│   ├── flight_board/
│   │   ├── Dockerfile                # 记录 PX4、Agent 与 Humble 运行环境的来源
│   │   ├── image.sh                  # 固定 tar 的导出、校验和加载
│   │   ├── compose.yaml              # 同一镜像的 vehicle 与 clock 服务
│   │   ├── entrypoint.sh             # 加载 Humble 与传感器环境
│   │   ├── supervisor.py             # 进程管理、日志和健康检查

│   │   ├── build_workspace.sh        # 调用官方 build-ros-humble，补充项目参数
│   │   ├── build_as2.sh              # AS2 包集合预设
│   │   └── cmake/                    # 目标 libyaml 等 CMake 适配
│   ├── robopi/                       # 板端环境、进程管理与诊断
```

## 初始化会产生什么

`bash scripts/prepare_sources.sh` 只初始化 `.gitmodules` 声明的两个活动 fork，
不生成根目录 `aerostack2/` 或 `px4_msgs/`。

OHOS 项目准备入口会在 `OHOS_WORK_ROOT` 下创建 SDK、官方工具链及 ROS 安装的
隔离副本，以及 `ws/src` 工作区。固定 px4_msgs、vision_msgs、mocap4r2_msgs、
PID 与 RMW 源码在此准备；编译缓存和产物也留在该工作区。
默认 `OHOS_WORK_ROOT=artifacts/ohos-as2`，不是主仓库中的源码依赖目录。

`vendor/` 是可选的本地重建输入目录，固定归档的文件名和 SHA256 记录在
flight_board Dockerfile 中，归档不随源码交付。加载正式 tar 不需要该目录。

## 本机配置与交付物

- `.env`：从 `.env.example` 配置设备和目录，忽略且不交付。
- `config/resources.local.yaml`：外部场景路径，忽略且不交付。
- `artifacts/`：隔离工作区、镜像 tar、本机日志和运行记录；新产物不纳入 Git。
- flight_board tar 与 `.sha256`：源码仓库之外提供的正式镜像交付物，见[加载说明](../deployment/flight_board/README.md#使用固定镜像)。

官方 builder 和基础开发环境由用户按[官方指南及项目说明](../deployment/oh-ros-build/README.md#前置条件)准备。
仓库不要求创建或接收派生的 OHOS builder 镜像。
