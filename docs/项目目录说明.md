源码准备脚本还会生成以下目录，当前本地快照尚未包含：

```text
01-aerostack2-integration/
├── aerostack2/                             # AS2 核心、状态估计、控制器与 Behavior 上游源码
└── px4_msgs/                               # PX4 与 ROS 2 通信消息定义
```

五个自建 ROS 2 包的包名均带 `uav_` 前缀。各 Python 包中的 `__pycache__/` 是自动生成的缓存，树中省略；`package.xml`、`setup.py`、`setup.cfg` 或 `CMakeLists.txt` 等包描述与构建文件也未逐一展开。

修改任务从 `planner_framework/examples/` 入手，修改参数默认值或 schema 从 `planner_framework/registry/` 入手，完整启动从 `deployment/integration/` 入手。运行生成的 `artifacts/resolved/` 用于复现和排错，不作为手工维护的任务源文件。
