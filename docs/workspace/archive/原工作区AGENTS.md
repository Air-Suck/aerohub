这是一个UAV项目，目标如下

# 最终目标

基于国产操作系统，搭建一个可即插即用（软硬件）的UAV软硬件系统

## 硬件

前期：飞控板（运行飞控）+算力板（运行飞行脑）

后期：一体化

## 软件

- 基座：国产操作系统
- 飞控：使用PX4
- 上层软件：
  - 无人机大脑：上层任务拆解+底层飞控调用（项目后期），需要支持单机和多机
  - model hub：自动实现多种算法/模型在不同硬件平台上的适配

## demo

- 高速穿梭机：20m/s左右的丛林避障
- 反无人机无人机
